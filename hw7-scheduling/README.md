# HW7-SCHEDULING 

*by Yelena Mkrtchyan*

The solution is contained in the pss.c file.

## Instruction

To execute the code in the solution file, you need to:
1. compile and link an executable:
	`gcc pss.c -o programname`
2. run the executable
	`./programname`
3. input the number of processes you want to simulate upon hint,
ending the line with "enter" (`newline`, `"\n"`)
4. for each process, enter the arrival time and the burst time, 
separating them with a space (" ") and ending each line with
"enter" (`newline`, `"\n"`)
5. see the results of the simulation

------------------------- **DISCLAIMER** -------------------------

Upon the requirements of the assignment, the SJF algorighm
does not realistically account for the arrival time of 
the processes.
